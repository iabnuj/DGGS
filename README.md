# DGGS

数字战场离散全球网格（DGGS）相关工作区：领域梳理 + 编码核 + 后续 Demo。

## 结构

```text
docs/                     领域与设计文档
packages/grid-core/       网格编码核（由 catnuko/geosot 吸收）
```

## 快速开始（编码核）

```bash
cd packages/grid-core
npm install
npm test
```
