# 导入入格级别：文件估算 + 可改

**日期:** 2026-07-29  
**状态:** 已批准，进入实现

## 目标

导入 GeoJSON 时，优先按文件几何特征自动建议 GeoSOT level，用户可在确认后再入格；不再默认绑定相机自动调级。

## 行为

1. 选文件 → 解析 → `suggestIngestLevel` → 内联确认区（建议级、理由、滑条 8–16）。
2. 「确认入格」用用户选定 level 调用现有 `ingestGeoJsonText`。
3. 「取消」丢弃待导入内容。

## 算法（方案 B）

- 特征长度 \(d\)（米）：
  - 点：采样最近邻距离中位数（不足则用 bbox 对角线 / √n）
  - 线：采样折线段长中位数
  - 面：采样 √(近似面积) 中位数
  - 混合类型：合并各样本再取中位数
- 映射：在 L8–L16 中取满足 `cellSize(L) ≤ d` 的**最粗**级（最小 L）
- `cellSize(L) = (180 / 2^L) × 110574`
- 无法估算时回退到当前显示级，并在理由中说明

## 非目标
