# 突击通道主戏 + 分级态势（Demo 包装）

**日期：** 2026-08-04  
**状态：** 已确认（用户要求按既定方案改造并生产一键数据包）  
**对应需求：** `docs/xq.md` §(4) ①⑧

## 目标

把现有 A* + 场约束抬成可汇报的「空中突击通道」主线，并用轻量「任务层级」撑起分级态势。

| 能力 | 交付 |
|------|------|
| 预置态势数据 | `public/demo/assault/` 一键包（高程/风速/电磁/雷达 + 部队点 + manifest） |
| 作战化命名 | 侧栏「空中突击通道」；场图层业务别名；结果层「突击通道 / 禁行区」 |
| 一键通道 | 加载演示包后写入起终点、打开威胁场、可一键计算通路 |
| 约束开关对比 | 保留全约束通路，关闭某一约束再算，双路径对照 |
| 分级态势 | 任务层级滑条：按 `taskLevel` 过滤部队标注；可选卷粗选中格 |

## 非目标

- 正式军标符号库、真·禁飞空域多边形编辑
- 聚类分析⑦、立体布尔全链路
- 替换现有通用空间分析入口

## 数据包

- 区域：和静测区约 `86–87°E, 42–43°N`，GeoSOT **L12** 连续 cover（与现有场样本同级）
- 场：`elevation`（合成高程，免 GeoTIFF）、`wind_speed`、`em_intensity`、`radar_coverage`
- 态势点：`units.geojson`（蓝方出发/目标、敌雷达站等，带 `taskLevel` / `role` / `label`）
- `manifest.json`：起终点编码、默认约束、图层显示名、推荐相机

生成：`node scripts/gen-assault-demo.mjs`

## UI

1. LeftDrawer：`航线通路规划` → `空中突击通道`
2. RoutePlanTab：加载演示态势、计算突击通道、约束对比、结论卡
3. DisplayTab 增补「任务层级」：过滤 `assault_units` 图层要素；状态栏提示当前可见部队粒度

## 验收

1. 一键加载 → 图层出现作战别名 + 起终点已填 + 威胁场可见  
2. 计算突击通道 → 橙通路 + 灰禁行 + 结论文案  
3. 对比关雷达 → 两条通路可区分  
4. 调任务层级 → 部队点增减
