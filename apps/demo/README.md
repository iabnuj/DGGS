# 格网引擎

基于 **GeoSOT（地理空间剖分网格）** 统一编码的桌面 / 浏览器演示应用。以 Cesium 三维地球为载体，把点、线、面、栅格等多源数据挂接到离散网格单元上，完成「编码 — 入格 — 存储 — 选格查询 — 尺度变换 — 可视化」闭环，作为格网孪生引擎子系统的汇报与验证前端。

技术栈：React + Vite + Cesium；桌面端 Electron + SQLite（`SqliteWarehouse`），浏览器端内存仓（`MemoryWarehouse`）。

---

## 理论背景

### 离散全球网格（DGGS）

传统 GIS 多用连续坐标与图幅组织空间数据，跨源融合、局部更新与多尺度联动成本高。离散全球网格系统（Discrete Global Grid System, DGGS）将地球表面（及立体空间）剖分为层级化、可索引的网格单元，用**网格编码**作为统一空间主键：同一编码可挂接影像、矢量属性、环境场值等，实现「以格为砖」的组织方式。

### GeoSOT 剖分与编码

本引擎编码核（`@dggs/grid-core`）对齐 **GeoSOT / GB/T 40087** 一脉公开算法（非正式军标合规认证实现）：

| 概念 | 说明 |
|------|------|
| 递归剖分 | 按层级将空间二分（或等价规则）细化，形成父子网格树 |
| 网格编码（GridCode） | 每个单元的唯一标识，可正反算经纬度范围 |
| 多尺度 | 粗格（低层级）覆盖大范围，细格（高层级）逼近细节 |
| 码代数 | 父格 / 子格、邻域、包围盒覆盖（`coverBBox`）等集合运算 |
| 应用换算 | 支持与经纬度、方里网等表述的对照（界面展示编码与范围） |

业务数据不再只按文件或图幅存，而是：选定层级 → 用网格集合覆盖对象 → 属性写入对应格 → 按编码检索与更新。实体变化时只需改相关格属性，更新粒度更细、响应更快。

### 与子系统建设目标的关系

完整「格网孪生引擎」涵盖编码、语义表征、环境入格、时空分析、场可视化、数据管理与智能问答等模块。**本应用是其中已落地的底座验证面**：重点演示统一 GeoSOT 编码下的网格绘制、多源入格、本地仓管理与交互可视化；布尔分析、通道分析、智能问答等能力见仓库方案文档，尚未全部进入本 Demo。

## 功能一览与目标

| 功能 | 目标 | 当前能力 |
|------|------|----------|
| **网格底座绘制** | 按视窗与层级铺设 GeoSOT 格网，形成统一空间骨架 | 显隐、边框/填充/编码标注、颜色与透明度、拉伸、随相机自动调级 |
| **多源数据入格** | 异构数据映射到指定层级网格，挂接属性与片段几何 | GeoJSON；桌面另支持 Shapefile、GeoTIFF（含 chip 上图） |
| **选格与查询** | 用交互选定网格集合，查看入格内容与编码信息 | 点选 / 画线选格 / 画面选格；右侧详情、定位、复制编码 |
| **尺度卷粗 / 细化** | 在选中集合上做父级聚合或子级拆分，验证码代数 | 「卷粗一级」「细化一级」（改选中编码，非整图缩放） |
| **片段上图** | 将入库裁剪后的矢量片段叠到地图，核对入格结果 | 按条或全部上图 / 取消上图 |
| **地图与态势底图** | 提供可读地理语境，支撑汇报展示 | 卫星 / OSM / 深色底图、地名注记、地形、光照、2D/3D、中国视角重置 |
| **本地数据仓** | 入格结果可持久、可再打开 | 浏览器内存；桌面 SQLite；菜单打开/保存网格 JSON |
| **状态底栏** | 运行时可读性 | 经纬度、GridCode、FPS、当前视窗格数等 |

## 使用说明

### 环境与启动

需 Node.js 18+、pnpm。在仓库根目录：

```bash
pnpm install
pnpm build:core           # 编码核
pnpm build:store          # 数据仓（桌面 SQLite 需要）

pnpm demo                 # 浏览器 → http://127.0.0.1:5173/
pnpm demo:electron        # Electron 桌面窗口
pnpm demo:dist            # 打本机安装包 → apps/demo/release/
```

安装包产物名形如：`格网引擎-<version>-<os>-<arch>.dmg` / `.exe`。

### 1. 浏览网格底座

1. 启动后地球默认面向中国区域，视窗范围内按当前层级绘制网格。
2. 打开左侧 **格网显示**：
   - **显示网格底座**：总开关。
   - **随相机自动调级**：滚轮缩放时按高度切换层级；关闭后可手动拖动层级滑条。
   - 边框 / 填充 / 编码文字、颜色、透明度、拉伸等按需调节。
3. 底栏可看当前指针附近的经纬度与 GridCode、帧率与格数。

### 2. 调整地图语境

左侧 **地图显示**：

- 切换底图（卫星影像 / 矢量路网 / 深色科技风）。
- 可选中文地名注记、地形贴地、光照阴影。
- **重置视角（中国）** 回到默认观察范围。

顶部工具条 **方块图标** 在 2D / 3D 场景间切换。

### 3. 导入并入格数据

左侧 **格网数据** → **导入数据**：

| 环境 | 支持格式 |
|------|----------|
| 浏览器 | GeoJSON / JSON |
| 桌面 | GeoJSON、Shapefile（.shp / .zip）、GeoTIFF（.tif / .tiff） |

流程：

1. 选择文件后，应用会建议入格层级（并说明理由，如按几何尺度估算）。
2. 用滑条确认层级（约 L8–L16，界面会显示该级大致边长）。
3. 确认入格：矢量按点/线/面覆盖写入网格仓；栅格按格切分并生成 chip，可高亮上图。
4. 图层列表中可显隐入格高亮、定位、删除图层。

桌面菜单还可 **文件 → 打开 / 保存 JSON**，导入导出网格记录；样例数据目录见 `resources/sample-data/`。

### 4. 选格与查看详情

顶部工具：

| 工具 | 用法 |
|------|------|
| **点选** | 单击一格 |
| **画线** | 在地图上画折线，收集线穿过的网格 |
| **画面** | 画多边形，收集面覆盖的网格 |
| **清除** | 清空当前选中集合 |

选中后右侧 **详情 / 网格详情 / 选中格网** 显示：

- GeoSOT 编码、层级、空间范围；可复制编码、定位飞行。
- 该格上的入格记录（来源、标签、属性等）。
- 有裁剪片段时可 **上图** 核对几何。

### 5. 尺度卷粗与细化

在右侧对**当前选中集合**（非整幅地图）：

- **卷粗一级**：选中格升到父级（L−1），编码聚合。
- **细化一级**：拆到子级（L+1），编码展开。

用于演示多尺度编码代数，以及「先粗后细」的查询与展示策略。

### 6. 典型演示路径（建议）

1. 启动桌面端 → 确认网格底座与底图。
2. 导入一份区域矢量（或样例）→ 确认建议层级 → 入格。
3. 点选或画面选格 → 右侧查看属性与片段上图。
4. 对选中集合做一次卷粗、一次细化，对照编码变化。
5. 若有 GeoTIFF，演示栅格入格与 chip 高亮。
6. 保存 JSON / 说明本地 SQLite 仓路径（用户数据目录下的库文件）。
